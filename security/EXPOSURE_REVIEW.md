Evidence is saved locally in the ignored `audit-output/exposure-review.json`. Reproduce the public checks with `npm run security:review` after installing/building the project, with read access to repository history and network access to official Solana and Vercel endpoints. The script locates the last historical addition/modification even after removal has been committed. Online failures are reported as incomplete checks.

The review queries the address account, token accounts owned by it, and conventional upgradeable-program authority records on devnet/mainnet-beta. It does not enumerate every possible custom-program role, delegated permission, private/off-chain service, historical state, or other network. It establishes no remaining authority in the resources checked at review time, not universal revocation of an Ed25519 secret. If a separate system is found to trust this key, replace that system's authority immediately.

Git history and external copies still contain retired material. Working-tree removal and application blocking do not erase those copies. Any destructive history rewrite requires coordination; none was performed in this task.
